# Excel Sales Dashboard

## Project Overview
This project focuses on analyzing sales data and presenting important insights through an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- PivotTables
- Charts
- Slicers
- Excel Formulas

## Key Features
- Sales data analysis
- Interactive dashboard
- Sales visualization
- Payment method analysis

## Objective
To make sales information easier to understand through interactive reports and visualizations.
